# 🌌 Portafolio Futurista — MikeDev

Un portafolio web moderno, con estética **futurista** y efectos dinámicos, creado para mostrar mis proyectos, habilidades y experiencia en desarrollo web.  
El diseño combina **tecnología, minimalismo y animaciones suaves**, inspirado en interfaces tipo _Windows Dock_ y efectos _glassmorphism_.

---

## 🚀 Características Principales

- **Diseño Futurista** con gradientes, brillos y sombras suaves.
- **Navbar tipo Dock** con iconos interactivos y tooltip.
- **Reloj en tiempo real** estilo Windows (hora y fecha en formato 24h).
- **Botón “Ir Arriba”** con icono moderno y efecto de aparición.
- **Transición suave** entre secciones (scroll animado).
- **Sección de Skills Responsive**, organizada por categorías.
- **Sección de Datos** con animaciones y efecto “glass”.
- **Footer adaptable** con enlaces sociales y fondo con transparencia.

---

## 🧠 Tecnologías Utilizadas

- **HTML5** — estructura semántica.
- **CSS3 / Flexbox / Media Queries** — diseño responsive y efectos visuales.
- **JavaScript (ES6)** — reloj dinámico, scroll suave y animaciones.
- **Boxicons / Font Awesome** — iconografía moderna.
- **Bootstrap 5** — sistema de grillas responsivas.

---

## 📱 Adaptabilidad

- Totalmente responsive en **móviles, tablets y desktops**.
- Elementos ajustados mediante `flex` y `media queries` optimizadas.
- En móviles pequeños se ocultan elementos decorativos para mejorar legibilidad.
